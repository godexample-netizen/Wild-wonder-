# Wild Wonder

Wild Wonder is a bird and nature documentary website with short-form documentary topics, bird facts, and a student field lab for college and university learners.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production site is generated in `dist/`. This project is prepared for static hosting such as Cloudflare Pages. The documentary cards currently link to YouTube topic searches; they are not embedded or hosted Wild Wonder episodes yet. The newsletter form is a front-end demo and does not collect email addresses until connected to an email service.
